# [mid] #0347 前 K 个高频元素

给你一个整数数组 `nums` 和一个整数 `k` ，请你返回其中出现频率前 `k` 高的元素。你可以按 **任意顺序** 返回答案。

### 示例 1：

**示例 1：**

- 输入：`nums = [1,1,1,2,2,3], k = 2`
- 输出：`[1,2]`

**示例 2：**

- 输入：`nums = [1], k = 1`
- 输出：`[1]`

**示例3：**

- 输入：`nums = [1,2,1,2,1,2,3,1,3,2], k = 2`
- 输出：`[1,2]`

## 思路

- 用哈希表统计每个元素出现的频率
- 用桶排序将频率相同的元素放在同一个桶中
- 【或】用小根堆维护前 k 个高频元素
