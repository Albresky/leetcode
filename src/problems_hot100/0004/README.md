# [hard] #0004 寻找两个正序数组的中位数

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))`。

**示例 1：**
- 输入：`nums1 = [1,3], nums2 = [2]`
- 输出：`2.00000`
- 解释：合并数组 = [1,2,3] ，中位数 = 2

**示例 2：**
- 输入：`nums1 = [1,2], nums2 = [3,4]`
- 输出：`2.50000`
- 解释：合并数组 = [1,2,3,4] ，中位数 = (2 + 3) / 2 = 2.5

## 思路

寻找两个有序数组的中位数，本质上等效于寻找两个有序数组中的“第 `k` 小的元素”。当数组总长度为奇数时，中位数是第 $(m+n)/2 + 1$ 小的元素；当总长度为偶数时，中位数是第 $(m+n)/2$ 小和第 $(m+n)/2 + 1$ 小元素的均值。通过比较两个数组当前可用部分的第 $k/2$ 个元素，我们可以一次性排除掉 $k/2$ 个绝对不可能是目标的元素，从而每次将搜索规模缩小一半，达到 $O(\log(m+n))$ 的时间复杂度。
