# mid #0128 最长连续序列

**要求：** 时间复杂度为 O(n)。

## 思路

>题目的**连续**是指 **严格单调**。

由于题目要求 O(n) 的复杂度，因此不能进行排序（最小$n \cdot log(n)$，然后又避免不了遍历数组，因此想到哈希表，具体步骤：

- 将 vector 初始化到 set
- 对每个集合元素 x，依次判断 x+1是否在集合中，统计长度 maxl
    - 先考虑 x-1 是否在集合中，若在则跳过该x（显然，x-1开始的序列一定比x开始的序列长，此时没必要再统计x开始的序列）
    - 对每个元素 x+1，考虑是否在集合中，一直遍历，直到不在
    - 更新 maxl
    - **[优化]** 更新 maxl后，其实不用一直遍历剩余的每个x。此时考虑maxl是否> set.size()/2，若是，则已找到最终maxl
        - 解释：在集合set中，若存在连续链条 $l_a > set.size()/2$，则一定不存在另一条连续链条 $l_b > set.size()/2$，否则总长度将超过 set.size()
