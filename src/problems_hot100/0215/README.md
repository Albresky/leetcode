# [mid] #0215 数组中的第 K 个最大元素

经典 Top-K 算法。

用递减快速选择。

## 思路

（快排）烧瓶分组 + 分治递归：
- 先从输入数组 nums 选个哨兵 x，进行分组：
  - 若 **x > nums**, 塞进 大头 gt
  - 若 **x < nums**, 塞进 小头 lt
  - 否则 塞进 eq
- 分完组后判断 k 在哪头：
  - 若 **k < gt.size()**，在大头，递归大头
  - 若 **k > nums.size - lt.size()**，在小头，递归小头
  - 否则 k 就在 eq，返回 x 即可

为避免极端情况每次选两头（产生 **0, 1, n -1** )的情形，每次选 x 都从 nums 随机选。
eq 相等分组用于避免快排算法的退化，若 eq，直接返回 x。

平均复杂度：

$O_s=O(n)$

$O_t=O(n)$

---
上述方法需要每次递归维护一组 vector，造成空间复杂度大。下面**改成三路原地分组：**

## 思路：

 - 维护 3 个指针：l, r, i。分别指向：大头gt的右边界+1（即eq左边界），小头 lt 左边接（即eq右边界），扫描指针当前位置
 - 从 left..right 随机选一个哨兵 x
 - i 从 左到右依次扫描
   - 若 **num[i]>x**，和大头交换：
     - swap(nums[l], num[i])
     - ++l
     - ++i (因为是从左到右，从大到小扫描，换过来的数必为 x，它小于大头，故i右移) 
   - 若 **num[i]《x**，和小头交换：
     - swap(nums[l], num[i])
     - --r
     - i不动 (因为是从左到右，从大到小扫描，换过来的数大小未知，故i不动，等待下次循环比较nums[i]和x的大小)
