# [hard] #0051 N 皇后

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 `n` 皇后问题 的解决方案。

每一种解法包含一个不同的 `n` 皇后问题 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**示例 1：**
- 输入：`n = 4`
- 输出：`[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]`
- 解释：如上图所示，4 皇后问题存在两个不同的解

**示例 2：**
- 输入：`n = 1`
- 输出：`[["Q"]]`

## 思路

回溯思路和 [#0131](../0131/README.md)、[#0022](../0022/README.md) 等类似，这里关键是 N 皇后问题的 合法判定条件，归纳有 3 点：

用 3 组状态维护：
- 1. 列占用。1 维数组 col[n] 维护各列是否有 N 皇后
- 2. 主对角线占用。1 维数组 diag1[2*n-1] 维护主对角线方向是否有 N 皇后
- 3. 副对角线占用。1 维数组 diag2[2*n-1] 维护副对角线方向是否有 N 皇后

> 对于矩阵中任意元素，主对角线方向的元素，其坐标索引有 $(x-y) \in [-n+1,n-1]$；副对角线方向的元素，其坐标索引有$(x+y) == constant$
