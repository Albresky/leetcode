# [mid] #0189 旋转数组

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。


**示例 1:**

**输入:**  nums = [1,2,3,4,5,6,7], k = 3

**输出:**  [5,6,7,1,2,3,4]

**解释:** 

向右轮转 1 步: [7,1,2,3,4,5,6]
向右轮转 2 步: [6,7,1,2,3,4,5]
向右轮转 3 步: [5,6,7,1,2,3,4]

**示例 2:**

**输入：** nums = [-1,-100,3,99], k = 2

**输出：** [3,99,-1,-100]

**解释：** 

向右轮转 1 步: [99,-1,-100,3]
向右轮转 2 步: [3,99,-1,-100]

## 思路

两种方法。

**法一**：额外维护一条数组存储翻转结果

**法二**：考虑直接原地翻转数组，翻转顺序：1) [0,len-1]; 2) [0, k%len - 1]; 3) [k%len, len - 1]
