# [mid] #0142 环形链表 II

给定一个链表的头节点  head ，返回链表开始入环的第一个节点。 如果链表无环，则返回 null。

## 思路

> 哈希表方法空间复杂度 O(n)。
> 这里主要复盘利用快慢指针的 Floyd 判圈算法，空间复杂度 O(1)。

**设**： 快慢指针步长分别为 *2*、*1*；表**头到入环节点**长度为 *x*，**环长**为 *y*。

如果快指针走到 null，说明无环。

下里我们考虑有环：

- 假设快慢**相遇**时，慢指针共走 s 步，此时块指针走了 2s 步；且有 $2s-s=ky$，即此时 $s=ky$；
- *从慢指针入环的时刻开始计算*，它走了 $(s-x)$ 步，即 $(ky-x)$ 步。这意味慢指针此刻再走 x 步，就会到入环口（不一定是第一次到）。那么，我们在快慢指针相遇的时刻起，从头节点以步长 1 开始行动一个指针，该指针将和慢指针在 $\le x$ 步时相遇在入环口。
